## Description
Wire up the input directory monitoring to trigger the orchestrator pipeline. Handle file correlation (multiple files per submission) and ensure clean handoff.

## Technical Details
- **Component**: Pipeline Entry Point
- **Layer**: Infrastructure
- **Inputs**: File system events or polling on input directory
- **Outputs**: Orchestrator invocation per submission
- **Key Logic**:
  - Monitor input directory (polling or filesystem watcher)
  - Correlate files: all files present at trigger time = one submission
  - Invoke Orchestrator Agent with file list
  - Move processed files to "processed" subdirectory
  - Handle concurrent submissions (queue or parallel with isolation)

## Acceptance Criteria
- [ ] AC-1: New files in input directory trigger pipeline
- [ ] AC-2: Multiple files grouped as single submission
- [ ] AC-3: Processed files moved out of input directory
- [ ] AC-4: Concurrent submissions don't interfere
- [ ] AC-5: Clear error if input directory inaccessible
