## Description
Build the Research Agent's company research capability. Searches public information about the prospect customer to provide business context in the report.

## Technical Details
- **Component**: Research Agent
- **Layer**: Service
- **Inputs**: Company name and primary address from LocationManifest
- **Outputs**: Company research summary with source citations
- **Key Logic**:
  - Extract company name from submission data (first location or separate company field)
  - Construct search queries: company name + industry, company name + news, company name + operations
  - Strip all contact PII from queries
  - Execute web search, parse results via LLM
  - Extract: industry, size/revenue (if public), operations summary, relevant recent news
  - Store with source URLs for citation

## Acceptance Criteria
- [ ] AC-1: Company overview retrieved (industry, operations description)
- [ ] AC-2: Relevant news or risk-relevant events captured
- [ ] AC-3: All findings have source URL citations
- [ ] AC-4: No PII in search queries
- [ ] AC-5: Graceful handling when company not found (flag in output)
