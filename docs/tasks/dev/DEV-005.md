## Description
Build the Research Agent's environmental risk search capability. For each location in the manifest, perform web searches to gather natural disaster risk data, historical events, and 10-year climate projections.

## Technical Details
- **Component**: Research Agent
- **Layer**: Service
- **Inputs**: LocationManifest (all locations with addresses)
- **Outputs**: ResearchResults keyed by location_id with source URLs
- **Key Logic**:
  - For each location, construct search queries using: address, city, state, risk category
  - Risk categories to research: flood, earthquake, hurricane, tornado, wildfire, hail, storm surge, tsunami, volcanic, landslide, sinkhole, winter storm, lightning, 10-year climate projections
  - Strip PII fields (contact name, phone, email) before constructing queries
  - Execute web search via Bing Grounding API
  - Parse results via LLM to extract relevant risk data points
  - Store: location_id, risk_category, findings, source_url, retrieval_timestamp
  - Handle rate limiting: queue with exponential backoff
  - Handle no results: flag location+category as "no public data available"
  - Parallel execution across locations (respect rate limits)

## Acceptance Criteria
- [ ] AC-1: Every location in manifest receives research queries
- [ ] AC-2: All 14 risk categories queried per location
- [ ] AC-3: Source URLs captured for every data point
- [ ] AC-4: No PII (contact name/phone/email) in any search query
- [ ] AC-5: Results keyed by location_id (manifest cross-reference)
- [ ] AC-6: Rate limiting handled gracefully (backoff, no crashes)
- [ ] AC-7: Locations with no search results flagged, not dropped
- [ ] AC-8: 10-year climate projection data included where available
