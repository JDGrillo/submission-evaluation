## Description
Build the Validation Agent's location count integrity checking. Verifies at every pipeline stage that the exact set of locations from the manifest is preserved — no additions, no omissions. Has veto power over report generation.

## Technical Details
- **Component**: Validation Agent
- **Layer**: Service
- **Inputs**: LocationManifest (ground truth), outputs from each pipeline stage
- **Outputs**: Validation result (pass/fail) + audit entries
- **Key Logic**:
  - Accept manifest hash + count as ground truth reference
  - At each stage boundary, receive output and verify:
    - Count matches manifest count
    - All location_ids from manifest present in output
    - No extra location_ids introduced
  - If mismatch:
    - Produce detailed diff (which IDs missing, which IDs extra)
    - Halt pipeline
    - Log to audit trail with full details
    - Trigger retry of failed stage (up to 3x)
    - If retry fails, produce error report for analyst
  - If pass: record audit entry (stage, count, hash verification, timestamp)

## Acceptance Criteria
- [x] AC-1: Validates location count at each pipeline stage transition
- [x] AC-2: Cross-references all location_ids (not just count)
- [x] AC-3: Any discrepancy halts pipeline immediately
- [x] AC-4: Produces detailed diff on failure (missing/extra IDs)
- [x] AC-5: Records pass/fail + details in audit trail
- [x] AC-6: Veto power: report cannot emit without validation pass
- [x] AC-7: Supports retry logic (re-invoke failed stage up to 3x)
