## Description
Build the Report Agent that generates a structured PDF report with executive summary, company overview, per-location risk analysis pages, and audit appendix.

## Technical Details
- **Component**: Report Agent
- **Layer**: Service
- **Inputs**: LocationManifest, RiskScores per location, ResearchResults, CompanyResearch, AuditEntries
- **Outputs**: PDF file saved to output directory
- **Key Logic**:
  - Use LLM to generate narrative content for each section:
    - Executive Summary: high-level risk overview, key findings, total locations analyzed
    - Company Overview: business context from research
    - Per-Location Pages (exactly N): risk scores table, narrative analysis, key risk factors, 10-year climate outlook, source citations
  - Assemble using PDF library (ReportLab or WeasyPrint):
    - Cover page with submission metadata
    - Table of contents
    - Executive summary
    - Company overview
    - Location sections (one per manifest location)
    - Audit appendix (location count verification, source list, validation results)
  - Default template: clean, professional, print-friendly
  - Visual elements: color-coded risk scores (green/yellow/orange/red), summary table
  - Verify output has exactly N location sections before saving

## Acceptance Criteria
- [ ] AC-1: PDF contains executive summary section
- [ ] AC-2: PDF contains company overview section
- [ ] AC-3: PDF contains exactly N location detail sections (one per manifest location)
- [ ] AC-4: Each location section has: risk scores, narrative, key factors, sources
- [ ] AC-5: Audit appendix shows: file names, location counts, validation status, sources
- [ ] AC-6: Table of contents with page references
- [ ] AC-7: Color-coded risk indicators for quick scanning
- [ ] AC-8: PDF saved to configured output directory
- [ ] AC-9: Fallback to markdown if PDF rendering fails
