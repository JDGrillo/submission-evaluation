## Description
Build the Ingestion Agent's Excel parsing capability. Reads `.xlsx`/`.xls` files from the input directory, extracts all location rows, and produces an immutable Location Manifest.

## Technical Details
- **Component**: Ingestion Agent
- **Layer**: Service
- **Inputs**: Excel files from local input directory
- **Outputs**: LocationManifest with all extracted locations
- **Key Logic**:
  - Scan input directory for `.xlsx` / `.xls` files
  - Read each sheet, detect header row (match known column names)
  - Extract each non-empty row as a Location record
  - Map columns to Location model fields (handle column name variations)
  - Flag rows with missing critical fields (address) but include them
  - Construct LocationManifest, log count, compute hash
  - Handle: corrupt files (skip with log), empty sheets (skip), locked files (retry 3x)

## Acceptance Criteria
- [ ] AC-1: Reads all `.xlsx` and `.xls` files from configured input directory
- [ ] AC-2: Extracts all location rows with full field mapping (~45 columns)
- [ ] AC-3: Produces LocationManifest with correct count matching source rows
- [ ] AC-4: Each location assigned a unique ID
- [ ] AC-5: Missing fields flagged (not dropped) — location still in manifest
- [ ] AC-6: Corrupt/unreadable files logged and skipped without crashing
- [ ] AC-7: Empty rows and header rows excluded from location count
