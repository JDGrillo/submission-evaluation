## Description
Build the Validation Agent's data integrity checking. Ensures no hallucinated or fabricated data appears in the report by cross-referencing all claims against input data and cited sources.

## Technical Details
- **Component**: Validation Agent
- **Layer**: Service
- **Inputs**: Draft report content, LocationManifest, ResearchResults with source URLs
- **Outputs**: Validated report (clean or with flags) + audit entries
- **Key Logic**:
  - Parse draft report into structured sections per location
  - For each location section:
    - Extract all numerical values and factual claims
    - Cross-reference against: (a) manifest input data fields, (b) research results with URLs
    - Flag any value not traceable to either source
  - For unsourced claims:
    - Mark with "[unverified]" tag or remove
    - Record in audit trail what was flagged/removed
  - Verify no addresses/locations appear that aren't in manifest
  - Use structured output from LLM (JSON) to enable deterministic checking
  - Produce audit summary: total claims checked, sourced %, flagged items

## Acceptance Criteria
- [ ] AC-1: Every numerical value in report traced to input or cited source
- [ ] AC-2: No fabricated location fields (addresses, names not in manifest)
- [ ] AC-3: Unsourced claims flagged with "[unverified]" or removed
- [ ] AC-4: Audit trail records all checks performed and results
- [ ] AC-5: Produces summary: claims checked, pass rate, flagged items
- [ ] AC-6: Works with structured LLM output format for deterministic checking
