## Description
Build the Ingestion Agent's PDF parsing capability. Extracts text from PDF files, uses LLM to identify location data in unstructured content, and merges supplementary locations into the manifest.

## Technical Details
- **Component**: Ingestion Agent
- **Layer**: Service
- **Inputs**: PDF files from local input directory; existing LocationManifest from Excel parsing
- **Outputs**: Updated LocationManifest (if new locations found) or supplementary data attached to existing locations
- **Key Logic**:
  - Extract raw text from PDFs (Azure Document Intelligence or PyPDF2/pdfplumber)
  - Send text to Azure OpenAI with structured extraction prompt
  - LLM returns location records with confidence scores
  - Deduplicate against existing manifest (match on address)
  - New locations added only if not already in Excel manifest; marked with PDF source + confidence
  - Low-confidence extractions flagged in audit trail
  - Supplementary data (narrative context about existing locations) attached to matching locations

## Acceptance Criteria
- [x] AC-1: Extracts text content from all PDF files in input directory
- [x] AC-2: LLM identifies location records from unstructured text
- [x] AC-3: Each extracted location has a confidence score
- [x] AC-4: Deduplication against Excel-sourced locations (no duplicates)
- [x] AC-5: Low-confidence extractions (<0.7) flagged in audit trail
- [x] AC-6: Manifest hash recomputed after merge; count updated
- [x] AC-7: If no locations found in PDF, continues without error (supplementary info only)
