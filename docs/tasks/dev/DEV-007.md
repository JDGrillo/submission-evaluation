## Description
Build the Analysis Agent that generates per-location risk scores by combining input data fields (ground truth) with research findings. Produces overall and per-category scores with explainable rationale.

## Technical Details
- **Component**: Analysis Agent
- **Layer**: Service
- **Inputs**: LocationManifest (with input risk zone fields), ResearchResults per location
- **Outputs**: RiskScore per location (overall + per-category) with rationale
- **Key Logic**:
  - For each location, combine:
    - Input data signals: flood_zone, earthquake_zone, hurricane_risk_zone, tornado_risk_level, wildfire_risk_level, hail_risk_level, etc.
    - Research findings: historical events, projected trends, proximity data
  - Scoring methodology (consistent across all locations):
    - Per-category score (1-10 scale): flood, earthquake, hurricane, tornado, wildfire, hail, storm_surge, climate_trend
    - Overall composite score (weighted average or LLM-synthesized)
  - Use LLM to synthesize rationale for each score (grounded in data)
  - Mark categories with insufficient data as "N/A" (not zero)
  - Ensure reproducibility: same inputs → same methodology applied

## Acceptance Criteria
